DEFAULT · APPLE SILICON

Qwen3.5-0.8B with vLLM-metal

Install vLLM-metal, then run this on the Mac where you open Mole Lab:

VLLM_METAL_MULTIMODAL_MODE=multimodal-native \
VLLM_ENABLE_V1_MULTIPROCESSING=0 \
vllm serve Qwen/Qwen3.5-0.8B \
  --max-model-len 2048 \
  --max-num-seqs 1 --gpu-memory-utilization 0.35 \
  --host 127.0.0.1 --port 8012

Choose Local model and click Connect. The default URL is http://127.0.0.1:8012; the model ID is discovered automatically.

OPTIONAL · DGX SPARK

DiffusionGemma with Jev

On a DGX Spark, follow the djev-spark recipe to run vLLM and its Jev decision server:

git clone https://github.com/mmastrac/djev-spark.git
cd djev-spark
cp .env.example .env
scripts/download-model.sh
docker compose up -d --build
scripts/smoke.sh

The recipe's Jev server listens on port 8011. On the computer running Chrome, use Node.js 24+ to start the bridge below. Replace 192.168.1.42 with your Spark's LAN address. Then choose Local Jev and click Connect; its default URL is http://127.0.0.1:8013.

git clone https://github.com/WindChimeRan/whack-a-mole-jav.git
cd whack-a-mole-jav
JEV_BASE_URL=http://192.168.1.42:8011 npm run bridge

A Jev server with CORS support can also be entered directly. For another hosted site, set BRIDGE_ALLOWED_ORIGIN to its HTTPS origin. Image mode uses the Jev server's images extension.
